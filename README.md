# 🎨 Design Studio

Një website statik profesional për një studio dizajni, i ndërtuar me HTML dhe CSS.

## 📋 Përmbajtje

- **Navigacioni** - Menu me lidhje të shpejta
- **Hero Section** - Seksioni hyrës me appel në veprim
- **Rreth Nesh** - Informacione për studiun
- **Portfolio** - Shembuj të punëve të realizuara
- **Shërbime** - Lista e shërbimeve të ofruara
- **Kontakt** - Formë për të na kontaktuar
- **Footer** - Informatat përfundimtare
